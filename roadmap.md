# Roadmap

## P0 · Verify before relying on the prototype in sessions

- Check the full arrival flow on real iPhone Safari, including safe areas, two-finger map pinch, landscape and return from the route-page game overlay.
- Verify game pause and Chinese-language play, along with the outstanding preference and draft flows in the [verification log](docs/verification-log.md).
- Field-check the five approximate locations, walking times and route geometry before using directions for real journeys.

## P1 · Improve data and operational readiness

- Replace illustrative sensory data and route notices with sourced observations and establish how updates are maintained.
- Add approved campus photography and regenerate route preview images after graph or seed changes.
- Choose a production tile provider and define offline expectations.
- Specify persistence, privacy, reporting and moderation before enabling shared Community publishing.

## P2 · Reduce maintenance debt

- Agree a plan for existing Prettier and React Refresh findings.
- Confirm scenario coverage against the BRP and compare the information architecture with the AllTrails reference when available.

Completed work and recorded coverage are in the [handoff](docs/HANDOFF.md) and [verification log](docs/verification-log.md).
