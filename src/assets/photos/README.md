# Photos (optional, drop-in)

Add a real photo named after a place id, route id or art key and the app uses it instead of the
built-in illustration — no code change. Examples: `marshgate.jpg`, `marshgate-cafe.webp`,
`stratford-marshgate.jpg`, `quiet.png`, `cafe.png`.

Keys: place ids and route ids in `src/data/demo.ts`; art keys: building, cafe, study, support,
quiet, route, park, water, station. Use photos you have the right to publish; credit people only
with their consent. Until then the illustrations are placeholders.
