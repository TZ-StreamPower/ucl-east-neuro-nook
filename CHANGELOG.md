# Changelog

## 18 November 2026 · Local team handoff

Key changes since the Lovable baseline in the current working tree.

- Renamed Campus to Explore and established four primary destinations. Added image-led discovery, featured cards, sensory filtering and a geographic map view.
- Added MapLibre and OpenFreeMap maps, Calmest and Quickest comparison, sensory overlays, checkpoints and place sheets, with a schematic fallback.
- Reworked place and route detail hierarchy, added three Community card layouts and labelled seeded demo posts. Added walk reflection and optional local sharing to Community.
- Added route-preview imagery, scene-derived card art and optional drop-in campus photos.
- Hardened game iframe load detection, retry and exit, and added focused game and information architecture tests.
- Added line-ending conventions, a typecheck command and visual checkpoint scripts. Recorded runs in the [verification log](docs/verification-log.md).
- Added team handoff documentation and archived the current working tree with its latest available UI previews.
